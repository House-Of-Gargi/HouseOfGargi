# Royal Product Photography Prompts & Generation Guide

This guide contains the exact prompts, dimensions, and specifications to generate the remaining **10 bespoke royal product images** for House of Gargi using Gemini (web app or Imagen 3).

---

## Quick Workflow Instructions

1. **Aspect Ratio / Size:** Use **3:4 portrait ratio** (or standard high-resolution portrait, e.g. 1024×1365px).
2. **Naming when saving:** You can simply save each generated image as **`1.png`**, **`2.png`**, **`3.png`**, ... up to **`10.png`** (or `.jpg`).
3. **Drop Location:** Paste them into either:
   - `c:\Users\shaws\ANGA9\HouseOfGargi\public\images\incoming\`
   - OR directly into `c:\Users\shaws\ANGA9\HouseOfGargi\public\images\products\`
4. **Auto-Process & Supabase Sync:**
   - Once pasted, tell Antigravity "I have pasted the images" or run:
     ```bash
     npm run sync:images
     ```
   - The script will automatically rename, move, update [`src/data/products.ts`](file:///c:/Users/shaws/ANGA9/HouseOfGargi/src/data/products.ts), and sync all live records to **Supabase**!
