# House of Gargi — Hero Banner Photography Prompts & Dimension Guide

This guide details the exact high-fashion generative prompts, fixed dimensions, aspect ratios, and negative-space framing rules for the **3 Hero Banner Concepts (6 images in total: 3 Desktop + 3 Mobile)** for House of Gargi.

---

## 1. Banner Dimension & Safe-Zone Technical Specifications

All text (headlines, subheadings, and buttons) is rendered entirely via **HTML/CSS code**. The generated images must contain **zero text, logos, or watermarks**, with intentional negative space for UI overlays.

| Device View | Target Dimensions | Aspect Ratio | Model Placement & Negative Space Rule |
| :--- | :--- | :--- | :--- |
| **Desktop View** | **`2400 × 1200 px`** (or `2560 × 1280 px`) | **`2:1`** (or `16:9` / `2400×1350`) | **Right 45% of frame**: Model positioned on the right side. **Left 55%**: Clear, softly lit background / architectural depth reserved for code-rendered headline and CTA button. |
| **Mobile View** | **`1080 × 1920 px`** (or `1080 × 1620 px`) | **`9:16`** (or `2:3` / `1080×1620`) | **Lower 60% / Center-Lower**: Model seated or positioned in lower center. **Top 40%**: Clean open air / soft backdrop space reserved for mobile navigation and headline overlay. |

## 2. Core Aesthetic Pillars

- **Pure Joy & Calmness (Ananda & Shanti)**: Authentic, warm, radiant smiles, serene composure, and natural eye contact that exudes warmth and welcoming quiet luxury.
- **Authentic Indian Heritage**: Real handwoven textiles (Kadwa Katan Silk, Garad-Korial, Patola, Zardozi, Chanderi), traditional 22kt temple jewellery, uncut Polki, and natural fresh jasmine (gajra).
- **Diversity & Inclusivity**: Representing diverse Indian skin tones (warm golden, wheatish, rich dusky tones), diverse regional handloom arts (Varanasi, Bengal, Gujarat, South India), and authentic cultural motifs.
- **Architectural & Ambient Depth**: Soft golden-hour sunlight, warm courtly lanterns, carved sandstone jharokhas, brass urlis filled with fresh rose petals, and textured ivory plaster.

## 4. Universal Negative Prompts & Parameter Guide

When generating these images in Midjourney, Imagen 3, Stable Diffusion, or DALL-E 3, always apply the following negative parameters to guarantee clean backgrounds without artificial text:

### Universal Negative Prompt
```text
text, words, typography, font, letters, slogans, watermarks, logo, UI elements, buttons, banners, borders, split screens, artificial frames, oversaturated colors, plastic skin, deformed hands, extra fingers, cartoonish, low resolution, blurry, harsh shadows, duplicate subjects
```

### Tool-Specific Parameters

#### Midjourney v6.1
- **Desktop**: Add `--ar 2:1 --style raw --v 6.1 --q 2 --no text typography watermarks logo`
- **Mobile**: Add `--ar 9:16 --style raw --v 6.1 --q 2 --no text typography watermarks logo`

#### Imagen 3 / Gemini Web App
- Set Aspect Ratio dropdown to **16:9** / **Wide** for Desktop, and **9:16** / **Portrait** for Mobile.
- Include the negative prompt explicitly at the end of your prompt text.

#### DALL-E 3 / ChatGPT Plus
- Prepend: *"Generate a photorealistic 8k wide banner image without any text, letters, or writing of any kind..."*

## 5. Implementation in Code (Next.js Responsive `<picture>` Tag)

Once generated, save the files into `public/images/` as:
1. `hero-desktop-1.jpg` & `hero-mobile-1.jpg` (Concept 1: Utsav Anand)
2. `hero-desktop-2.jpg` & `hero-mobile-2.jpg` (Concept 2: Shwet-Raktam)
3. `hero-desktop-3.jpg` & `hero-mobile-3.jpg` (Concept 3: Raj-Darbar)

In `src/app/(storefront)/page.tsx`, the responsive image is rendered using clean semantic HTML so that the browser automatically serves the mobile-optimized vertical image on small screens and the wide negative-space banner on desktop:

```tsx
<section className="hero">
  <div className="hero__bg">
    <picture>
      <source media="(max-width: 768px)" srcSet="/images/hero-mobile-1.jpg" />
      <img
        src="/images/hero-desktop-1.jpg"
        alt="House of Gargi — Handcrafted Heritage, Worn Today"
        style={{ width: '100%', height: '100%', objectFit: 'cover' }}
      />
    </picture>
  </div>
  <div className="hero__overlay" />
  <div className="hero__content">
    <h1 className="hero__tagline">Handcrafted Heritage, Worn Today.</h1>
    <p className="hero__subtitle">Luxury handmade Indian fashion — woven by hand, worn for a lifetime.</p>
    <Link href="/category/sarees" className="btn btn--gold">Explore the Collection</Link>
  </div>
</section>
```
